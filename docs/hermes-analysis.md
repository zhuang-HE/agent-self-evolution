# 📊 Hermes Agent 借鉴分析报告

> 分析对象：Hermes Agent (Nous Research)
> 版本参考：v0.7.0 ~ v0.8.0

## 1. Hermes Agent 概述

Hermes Agent 是 Nous Research 于 2026 年 2 月发布的开源 AI Agent 框架（MIT 协议），上线一个多月即获 60K+ GitHub Stars。核心差异化能力：**自托管、持久记忆、自动 Skill 创建、自我进化**。

### 技术栈
- 语言：TypeScript
- 存储：SQLite + FTS5 全文索引
- 模型：模型无关，支持 200+ LLM（OpenRouter / 本地 vLLM）
- 平台：CLI + 6 种消息网关（Telegram / Discord / Slack 等）

## 2. 记忆系统分析

### 2.1 三层记忆架构

| 层级 | 名称 | 作用 | 存储 |
|------|------|------|------|
| L1 | 会话记忆 | 当前对话上下文 | 内存 |
| L2 | 持久记忆 | 跨会话用户偏好和项目信息 | SQLite + FTS5 + LLM 摘要 |
| L3 | 技能记忆 | 解决方案模式和方法论 | SKILL.md 文件 |

### 2.2 FTS5 检索 + LLM 摘要

Hermes 的持久记忆采用 **FTS5（SQLite 全文搜索）+ LLM 语义摘要** 双重机制：
- **检索阶段**：FTS5 基于关键词快速定位相关记忆
- **理解阶段**：LLM 对检索结果进行语义摘要，提高相关性

**局限性**：FTS5 本质是全文搜索，复杂语义场景下检索精度有限。

### 2.3 对我们的借鉴

| Hermes 设计 | 我们的适配方案 |
|-------------|---------------|
| FTS5 全文索引 | Markdown 文件 + 关键词预检（轻量级替代） |
| LLM 摘要压缩 | MEMORY.md > 50KB 时触发摘要压缩 |
| 跨平台记忆共享 | 通过项目路径隔离的 MEMORY.md 分区 |

## 3. Skill 自动创建分析

### 3.1 Hermes 的机制

```
任务完成 → 提取执行轨迹 → 识别可复用模式 → 生成 SKILL.md → 自动调用
                                                    ↓
                                              后续使用中自我优化
```

- **触发条件**：使用内置 40+ 工具完成复杂任务后
- **生成方式**：从成功经验中自动提取规律
- **标准格式**：遵循 agentskills.io 标准
- **自优化**：后续使用中根据执行反馈自动迭代

### 3.2 对我们的借鉴

Hermes 的全自动创建存在质量风险（v0.7.0 有 780 个 Open Issues），我们采用**半自动**策略：

```
任务完成 → 自动识别可复用模式 → 生成 Skill 模板 → 用户审核 → 正式创建
```

保留了人工审核节点，可控性更强。

## 4. 自进化闭环分析

### 4.1 Hermes 的三层自进化

| 层级 | 机制 | 成本 |
|------|------|------|
| L1 提示词优化 | DSPy + GEPA 算法自动优化系统提示词 | $2-10/次 |
| L2 经验积累 | 执行轨迹 → 自动提取 → Skill 更新 | 纯 API 调用 |
| L3 模型微调 | tinker-atropos 导出 RL 训练数据 → 微调 | 需要 GPU |

### 4.2 对我们的借鉴

| Hermes 层级 | 适用性 | 我们的方案 |
|-------------|--------|-----------|
| L1 提示词优化 | ✅ 适用 | 暂未实现，作为远期目标 |
| L2 经验积累 | ✅ 适用 | 踩坑经验即时追加 + 定期消化为显式步骤 |
| L3 模型微调 | ❌ 不适用 | WorkBuddy 云端产品，无法微调底层模型 |

## 5. 风险与局限

| 风险 | 说明 | 应对 |
|------|------|------|
| 自动创建质量 | 自动生成的 Skill 稳定性存疑 | 保留人工审核节点 |
| 记忆膨胀 | 持久记忆无限增长 | 摘要压缩 + 定期整理 |
| 模型依赖 | 小模型（7B）下逻辑易崩溃 | 标注最低模型要求（64K context） |
| 检索精度 | FTS5 语义理解有限 | 关键词预检 + LLM 摘要双重机制 |

---

## 6. 结论

Hermes 的核心理念 **"让 Agent 从执行历史中学习"** 是正确的方向。我们的策略是**取其精华、控其风险**：

- ✅ 采用：Skill 候选识别、经验即时积累、记忆按需检索
- ⚠️ 适配：自动创建 → 半自动（加审核）、FTS5 → 轻量级关键词预检
- ❌ 不采用：RL 数据飞轮（平台限制）、全自动无审核（质量风险）
